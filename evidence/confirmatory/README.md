# New fixed-test readout experiments, 2026-10-13

This directory adds **new fitting and inference** to the historical evidence in the parent directory. It contains all 12 scheduled fits: nine ELF readouts (three nested training budgets, three fit seeds), and three LangFlow readouts. Every checkpoint is selected by validation agreement only. All 21 readout/test evaluations are retained, with 15,360 per-sequence count rows, 6,656 control rows, and 2,560 evaluator NLL/token-count rows.

Run `python confirmatory/verify.py` from the parent supplement directory, or run `python verify.py` here. Python 3.10+ and NumPy suffice. It checks the frozen protocol hash, disjoint splits, checkpoint selection histories, per-run agreement, macro agreement, predicted-EOS diagnostics, seed SD, 4,000-draw sequence-bootstrap intervals, paired budget improvements, frozen lookup, LangFlow same-phase controls, token groups, and corpus PPL. It prints a report and does not modify the package. These intervals are conditional on the three fitted models and fixed split, not population training-seed intervals.

ELF's historical pool had prior experimental use. Its new common test is disjoint for these fits but not globally untouched. `fresh_test` comprises 512 new generations never used for selection. `test` denotes the 1,024-sequence historical ELF test or the independent 512-sequence LangFlow test, according to `family`. `sequence_index` is the row within that declared test, consistently shared across fits and controls. The ELF split IDs refer to historical cache rows; fresh IDs are local row numbers.

LangFlow uses 128 positions and its native learned embedding table, whereas ELF uses up to 1,024 positions and a T5 interface. Its 1,024-sequence fitting set has fewer token examples than ELF's. Its native logits explicitly add a linear embedding skip. Phase controls compare each term's argmax to full native logits **at that same phase**, holding the full model's trajectory and self-conditioning fixed. They do not rerun ablated transport. LangFlow coverage strata are explicitly post-fit diagnostics.

Fresh ELF PPL uses the native validity mask for every readout before detokenization, then a common GPT-2-Large truncation limit of 1,024. This is an oracle-boundary readout diagnostic, not autonomous generation quality. Different detokenizations yield different evaluator token counts. All five methods and all three learned seeds are retained.

Source programs under `source/` document raw generation, fitting, inference, and plotting. They expect the original repository layout, local checkpoints and historical latent caches. They are not standalone GPU reproduction scripts; these large assets and token-level predictions are omitted. The portable scalar verifier does not independently verify the GPU measurements or native labels. Hashes, validation histories, and the small numerical lineage check make this boundary explicit.

## Explicitly post-initial-result token-budget follow-up

After observing the 1,024-sequence LangFlow result, `langflow_followup_protocol.json` froze a nested 8,192-sequence training extension, the same validation/test files, the same 4,096-update fitting budget, and all three original fit seeds. This is a follow-up informed by the first results, not part of the initial protocol. `followup/` retains all three additional fits, their comparisons to the original fits, and a special-token-mask sensitivity check. Its per-sequence CSV contains six fits (3,072 rows), including the three original LangFlow fits as paired controls. Across both studies there are 15 distinct fits and 16,896 distinct readout/sequence evaluations. Run `python verify_followup.py` here. Source scripts and selected-model hashes are preserved; no test-based checkpoint or seed selection is used.
